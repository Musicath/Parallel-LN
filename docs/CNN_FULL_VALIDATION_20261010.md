# One full mixed-axis CNN configuration on RTX 4090 (2026-10-10)

This is a **single random-label training cell**, not a reproduction of the
manuscript's 48-domain, three-seed CNN grids or their clean-label results.
The complete run used the isolated 65-file arXiv-code candidate archive
(SHA-256 `756eccbf5a25704ab17f8872f055ba68928c0920d68bebbfba537459daf8a070`)
on physical GPU 1, an NVIDIA GeForce RTX 4090. The runtime was Python
3.10.16, PyTorch 2.6.0+cu126 and torchvision 0.21.0+cu126; the historical
CNN grid used PyTorch 2.3.0+cu121 and torchvision 0.18.0+cu121. Timing is
therefore not compared as a reproduction metric.

## Matched configuration

The historical cell is the random-50k, depth-4, width-128 `bgn32k32`
(position-wise PLN[4]) run with model seed 0, data seed 20260902 and random
label seed 20260903. Both JSONs record 50,000 training examples, channel
width 128, four normalization layers, pool size 4, SGD learning rate 0.01,
momentum 0.9, no weight decay, Nesterov, affine normalization, or data
augmentation, batch size 128, 200 epochs and 528,266 model parameters. The
evaluation curve has the same 21 epochs in both files (epoch 1 and every
10 epochs through 200). The archived JSON has SHA-256
`7ebcdb670acf393e3830907be47d101560e2e3225f181fdefb8769336c215cbb`.

The intermediate training curves are close but not identical: the largest
absolute fitting-accuracy difference over their 21 matched evaluation epochs
is about 2.50 percentage points (epoch 50), and the candidate's epoch-100
accuracy is 99.314% versus 99.510% historically. Exact matching is not
expected across these software environments. Since both final accuracies
saturate at 100%, agreement here establishes that this standalone runner can
execute and fit **this cell** under the stated protocol; it does not resolve
relative performance among LN, GN, PLN or other grouping domains.
